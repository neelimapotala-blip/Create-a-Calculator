# Create-a-Calculator
1. Project Overview
Project Name: Smart Calculator

Technologies:
- Frontend: HTML
- Styling: CSS
- Logic: JavaScript
- Backend: Python Flask
- Database: SQLite
2. Features
1. Addition (+)
2. Subtraction (-)
3. Multiplication (×)
4. Division (÷)
5. Percentage (%)
6. Clear (C)
7. Delete (⌫)
8. Calculation history
9. Responsive design
10. Modern calculator UI
